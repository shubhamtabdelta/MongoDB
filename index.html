01

MongoDB Fundamentals

Learn what MongoDB is and where it fits in the MERN stack.

Topics

  • Database, DBMS, and RDBMS
  • NoSQL and document databases
  • SQL vs NoSQL; MongoDB vs SQL databases
  • Documents, collections, and databases
  • JSON vs BSON and ObjectId
  • Atlas, Community Server, Compass, and mongosh
  • MongoDB architecture and use cases

Practice tasks

  1. Explain MongoDB in your own words.
  2. Install MongoDB and Compass or use Atlas.
  3. Explain document vs collection.
  4. Compare a SQL row with a MongoDB document.
  5. Explain when a document database is suitable.
Checkpoint: Explain database → collection → document without notes.
02

Databases, Collections & BSON Types

Build a database and understand document structure.

Topics

  • Create and switch databases
  • Create, list, and drop collections
  • Strings, numbers, Boolean, arrays, objects
  • Dates, null, missing fields, and ObjectId
  • Embedded documents and nested fields
  • Lazy database creation
show dbs
use companyDB
db.createCollection("employees")
show collections
db.getCollectionNames()

Practice tasks

  1. Create `companyDB`.
  2. Create employees, companies, and departments collections.
  3. Insert a document with an address object.
  4. Store skills as an array.
  5. Explain null vs a missing field.
  6. Explain why `use` alone may not persist a new database.
03

Insert & Read Operations

Master the first part of CRUD.

Topics

  • insertOne() and insertMany()
  • find() and findOne()
  • Filters and projection
  • Automatic and custom IDs
  • countDocuments() and distinct()
  • Duplicate-key errors and insert results
db.employees.insertOne({
  name: "Rahul",
  age: 25,
  department: "IT",
  salary: 45000
})
db.employees.find({ department: "IT" })
db.employees.findOne({ name: "Rahul" })

Practice tasks

  1. Insert one employee and then ten employees.
  2. Find all employees and one employee by name.
  3. Display only names and salaries.
  4. Count all employees.
  5. List unique departments.
  6. Explain duplicate `_id` behavior.
04

Update & Delete Operations

Change documents safely and understand write operators.

Topics

  • updateOne(), updateMany(), replaceOne()
  • deleteOne() and deleteMany()
  • $set, $unset, $inc, $mul
  • $rename, $min, $max, $currentDate
  • Upsert and atomic updates
  • Soft delete vs hard delete
db.employees.updateOne(
  { name: "Rahul" },
  { $set: { age: 26 } }
)
db.employees.updateMany(
  { department: "IT" },
  { $inc: { salary: 2000 } }
)

Practice tasks

  1. Update one employee's age.
  2. Increase IT salaries by ₹2,000.
  3. Rename and remove fields.
  4. Use upsert for a record.
  5. Delete a test employee.
  6. Implement soft deletion with `isDeleted`.
  7. Explain update vs replace.
05

Comparison & Logical Operators

Write filters for real application requirements.

Operators

  • Comparison: $eq, $ne, $gt, $gte, $lt, $lte
  • Membership: $in, $nin
  • Logical: $and, $or, $not, $nor
db.employees.find({
  salary: { $gte: 30000, $lte: 80000 }
})
db.employees.find({
  department: { $in: ["IT", "HR"] }
})

Practice tasks

  1. Find salaries over ₹50,000.
  2. Find salaries between ₹30,000 and ₹80,000.
  3. Find employees aged 25 or older.
  4. Find IT or HR employees.
  5. Exclude Finance employees.
  6. Combine department and salary conditions.
  7. Explain `$in` vs `$or`.
06

Arrays, Nested Documents & Advanced Queries

Query structured data and update array elements.

Topics

  • $exists, $type, $expr, $regex, $mod
  • $all, $size, $elemMatch
  • $push, $addToSet, $pull, $pop, $each
  • Positional $, $[], and filtered positional updates
  • Dot notation and nested updates
  • $jsonSchema and $text overview
db.employees.find({
  skills: { $all: ["JavaScript", "MongoDB"] }
})
db.employees.updateOne(
  { name: "Rahul" },
  { $addToSet: { skills: "MongoDB" } }
)

Practice tasks

  1. Find employees with MongoDB skills.
  2. Find employees with at least three skills.
  3. Find documents where email exists.
  4. Find names beginning with A.
  5. Add an array value without duplicates.
  6. Remove a value from an array.
  7. Query an embedded address field.
  8. Explain `$push` vs `$addToSet`.
07

Sorting, Projection & Pagination

Build efficient list and search queries.

Topics

  • sort(), limit(), and skip()
  • Projection and field selection
  • Stable sorting
  • Offset vs cursor pagination
  • Filtered search and large result sets
db.employees.find()
  .sort({ salary: -1 })
  .limit(5)

db.employees.find()
  .skip(10)
  .limit(10)

Practice tasks

  1. Find the five highest-paid employees.
  2. Display page one and page two.
  3. Sort by joining date.
  4. Build a department filter.
  5. Explain why large skip values may be slow.
  6. Design pagination for one million records.
08

Schema Design & Relationships

Choose the right structure before building APIs.

Topics

  • Flexible schema and schema design
  • Embedding vs referencing
  • One-to-one, one-to-many, many-to-many
  • Data duplication and consistency
  • Unbounded arrays and the 16 MiB document limit
  • Schema versioning and polymorphic pattern
  • Subset, bucket, outlier, and computed patterns

Practice tasks

  1. Design users and profiles.
  2. Design companies and employees.
  3. Design products and orders.
  4. Choose when to embed an address.
  5. Model millions of transactions.
  6. Explain unbounded-array risks.
  7. Plan a backward-compatible schema change.
09

References, $lookup & Joins

Retrieve related data from separate collections.

Topics

  • ObjectId references and manual references
  • DBRef overview
  • $lookup, $unwind, $graphLookup
  • One-to-many and many-to-many joins
  • Missing relationships and join optimization
db.orders.aggregate([
  {
    $lookup: {
      from: "customers",
      localField: "customerId",
      foreignField: "_id",
      as: "customer"
    }
  }
])

Practice tasks

  1. Join customers and orders.
  2. Display orders with customer details.
  3. Find customers without orders.
  4. Calculate spending per customer.
  5. Join employees and companies.
  6. Compare `$lookup` and Mongoose `populate()`.
10

Aggregation Framework Fundamentals

Turn raw documents into reports and summaries.

Topics

  • Pipeline concepts
  • $match, $project, $set, $unset
  • $group, $sort, $limit, $skip, $count
  • $unwind
  • Accumulators: $sum, $avg, $min, $max, $first, $last, $push, $addToSet
db.employees.aggregate([
  {
    $group: {
      _id: "$department",
      totalEmployees: { $sum: 1 },
      averageSalary: { $avg: "$salary" }
    }
  },
  { $sort: { averageSalary: -1 } }
])

Practice tasks

  1. Count employees by department.
  2. Calculate average salary per department.
  3. Find the highest salary per department.
  4. Calculate total salary expenditure.
  5. Find the top five departments.
  6. Unwind product arrays.
  7. Explain why `$match` is often placed early.

Practice tasks

12

Indexing

Make common queries faster without over-indexing.

Topics

  • Single-field and compound indexes
  • Multikey, unique, partial, and sparse indexes
  • TTL, text, geospatial, hashed, wildcard indexes
  • Hidden indexes and index prefixes
  • Selectivity and covered queries
  • Equality-Sort-Range guideline
  • Index size and write overhead
db.employees.createIndex(
  { employeeId: 1 },
  { unique: true }
)
db.employees.createIndex({
  companyId: 1,
  department: 1,
  salary: -1
})
db.employees.getIndexes()

Practice tasks

  1. Create a unique employee ID index.
  2. Create a compound index.
  3. Choose index field order for a query.
  4. Explain why too many indexes hurt writes.
  5. Explain TTL and multikey indexes.
  6. Find redundant indexes.

Query Optimization & Performance

Measure query behavior instead of guessing.

Topics

  • explain("executionStats")
  • IXSCAN, COLLSCAN, FETCH, SORT
  • Documents and keys examined
  • Slow query logs and profiler
  • Connection pooling
  • Aggregation and pagination optimization
  • Memory, disk, and latency monitoring
db.employees
  .find({ department: "IT" })
  .explain("executionStats")

db.employees.stats()
db.serverStatus()

Practice tasks

  1. Create 100,000 test documents.
  2. Measure a query without an index.
  3. Add an index and compare execution stats.
  4. Investigate a slow aggregation.
  5. Compare offset and cursor pagination.
  6. Explain `IXSCAN` vs `COLLSCAN`.

Topics

Backup, Restore, Monitoring & Production

Prepare for recovery and routine operations.

Topics

  • mongodump and mongorestore
  • mongoexport and mongoimport
  • Backup retention and restore tests
  • Point-in-time recovery concepts
  • Disaster recovery, RPO, and RTO
  • mongostat, mongotop, dbStats(), collStats()
  • Logs, connections, CPU, memory, disk, upgrades
mongodump --db=mongoMastery --out=./backup

mongorestore \
  --nsFrom="mongoMastery.*" \
  --nsTo="mongoMastery_restore.*" \
  ./backup/mongoMastery

Practice tasks

  1. Back up a test database.
  2. Restore into a separate database.
  3. Explain backup vs replication.
  4. Plan backup retention.
  5. Explain RPO and RTO.
  6. Diagnose high CPU or slow queries.
  7. Plan a version upgrade.

Run backup commands in a test environment first and confirm the restore works. Production backup options depend on your deployment and recovery requirements.

05Final Project: Employee Management Database

Build a realistic database using MongoDB, Node.js, Express, and Mongoose. Keep the first version small, then add advanced features.

🗂️ Collections

Organizations, companies, employees, users, departments, attendance, leave requests, payroll records, and audit logs.

🔎 Employee management

Create and update employees, search by name or ID, filter by company and status, and paginate results.

📊 Reporting

Department headcounts, active employee counts, joining reports, attendance summaries, and leave statistics.

⚡ Data & performance

Schema validation, unique indexes, aggregation pipelines, explain plans, and query performance tests.

🔐 Security

Least-privilege database users, safe credentials, input validation, and access restrictions.

🛟 Reliability

Backup and restore tests, transaction workflows where needed, monitoring, and migration planning.

MERN integration checklist

  • Connect MongoDB using Mongoose.
  • Create schemas and models.
  • Build Express CRUD routes and controllers.
  • Validate request data and handle errors.
  • Use references and `populate()` appropriately.
  • Implement pagination and aggregation.
  • Add indexes based on actual query patterns.
  • Keep connection strings in environment variables.
